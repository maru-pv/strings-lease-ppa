ホーム

ログインすると最初に出る画面です。使うツールをここから選びます。

押す順番

  1. 商談で使うときは「光熱費まるごと比較ナビ」を選ぶ
  2. 発電の流れを見せたいときは「太陽光の仕組み体感ツール」を選ぶ
  3. 打ち合わせの準備は「提案パターン・ラボ」
  4. 管理者だけ「取引先管理」が出ます
  5. 終わったら一番下の「ログアウト」

困ったとき

「取引先管理」が出ない管理者の権限がある人にだけ出ます。必要なら管理者に頼んでください。
すぐログイン画面に戻されるログインの期限が切れています。もう一度ログインしてください。

ログイン

メールアドレスとパスワードで入ります。

押す順番

  1. メールアドレスとパスワードを入れる
  2. ログイン を押す

パスワードを忘れたとき

  1. パスワードを忘れた方 を押す
  2. 登録メールアドレスを入れて 再設定メールを送る を押す
  3. 届いたメールから新しいパスワードを決める。入力画面に戻るときは ログインに戻る

困ったとき

メールが届かない迷惑メールのフォルダを確認してください。それでも無いときは管理者に連絡してください。

光熱費まるごと比較ナビ ① 条件入力

お客様の暮らしを入れると、新築後の光熱費（電気ガス併用とオール電化）を試算します。営業がお客様の前で使う画面です。

押す順番

  1. 工務店名・担当者名・案件名 / お客様名を入れる（どの案件の試算かが記録されます）
  2. 家族人数・居住エリア・日中の在宅時間を選ぶ（新築後の電気代・ガス代が自動で入ります。実態に近ければそのままで大丈夫です）
  3. 現在の月間ガス代など、わかる所を直す
  4. オール電化にしたらいくら？を見る を押す

困ったとき

先に進めない赤い文字が出ている項目を入れてください（工務店名・担当者名・案件名・家族人数・エリア・金額）。
今の家より高く出る新築で家が広くなる分です。画面の「なぜ今より高い？」で説明できます。

光熱費まるごと比較ナビ ② オール電化なら？

電気ガス併用とオール電化の月額光熱費を並べ、オール電化で月いくら変わるかを見せます。

押す順番

  1. 上の大きな数字（月いくら変わるか）と内訳を説明する
  2. 発電の流れを見せたいときは 太陽光の仕組みをインタラクティブに体感する（別の画面で体感ツールが開きます）
  3. 仕組みはわかった！導入方法を比較する を押して ③ へ
  4. 入力を直すときは 入力に戻る

困ったとき

お客様に理由を聞かれた画面下の「なぜオール電化は安くなるの？」（エコキュートの省エネ性・基本料金の一本化・夜間電力・暮らしの安心）を使ってください。

光熱費まるごと比較ナビ ③ さらに太陽光なら？

太陽光を「リース」「購入」「建て得（PPA）」で入れたとき、30年でどれだけ得かを比べます。

押す順番

  1. 上のタブ リース 購入 建て得 を切り替えて、それぞれの30年の得と月々のイメージを見せる
  2. 購入は工務店ごとの kW単価（税抜）で計算します。初期費用は税込で出ます
  3. 正確な金額を出したいお客様には 具体的なシミュレーション試算はこちら（無料） を押し、下の「お客様用 導入診断」に進む
  4. ② に戻るときは オール電化の比較に戻る

困ったとき

数字が実際の見積と違う標準的な屋根条件での概算です。屋根の向き・面積・地域で変わります。詳細シミュレーションで確認してください。
リース料の金額月額・税抜で表示しています。

お客様用 導入診断（STEP1〜6）

お客様ご自身でも使える試算の画面です。比較ナビの ③ から進んだ場合は、入力済みの内容が引き継がれます。下の 次へ で進み、← で1つ戻ります。

STEP1 電気代電力会社のプランと毎月の電気使用量を選ぶ。使用量がわからないときは 目安を見る。
STEP2 プランリースの容量（月額・税抜）と、PPAを選ぶ。PPAは 建て得（LIXIL） と その他のPPA で切り替え。
STEP3 オプションエコキュートの設定（ソーラーモード／おひさまECO）と年間の使用量を選ぶ。
STEP4 試算結果リース・PPA・購入の30年の合計を並べて見せる。まとめへ で次へ。
STEP5 まとめ数字以外でリースが選ばれる理由を見せる。お問い合わせへ で次へ。
STEP6 お問い合わせお名前・電話番号（必須）などを入れて 問い合わせを送る。送ると担当者から連絡します。

困ったとき

使用量の注意が出る一般的な世帯より少ない使用量です。入力に間違いがないか確かめてください。合っていればそのまま進めます。
比較ナビから進むと STEP5 が無い選んだ比べ方によっては STEP4 から お問い合わせへ に直接進みます。

太陽光の仕組み体感ツール

発電・家で使う電気・売電・買電の流れを、1日の時間に沿って動かして見せます。体験用の概算で、試算結果の数字とは別物です。

押す順番

  1. 容量（6kW／8kW／12kW）と天気（晴れ／くもり）を選ぶ
  2. 時刻のつまみを左右に動かす。再生 で1日が自動で進み、一時停止 で止まる
  3. 家の中の家電（エアコン・IH調理・テレビ・EV充電・エコキュート）を押すと、使う電気が増えたり減ったりする

困ったとき

売電の金額を聞かれたこの画面の売電単価は説明用の仮の値です。金額は比較ナビの ③ で見せてください。

電気代まるごと見直し

太陽光をまだつけていない中国電力エリアの戸建てのお客様向けです。今の中国電力の契約からENEOSでんき（中国Aプラン）に切り替えた場合と、さらに太陽光をリースか購入でのせた場合を、続けて概算します。ログインしなくても開けます。

押す順番

  1. 1 お住まいの電気：オール電化（今は中国電力 電化Styleコースとして計算）かガス併用（今は従量電灯Aとして計算）を選ぶ
  2. 2 毎月の電気の使い方：家族の人数／電気代／使用量から選んで入れる。オール電化なら、平日の昼に使う割合をつまみで合わせる
  3. 3 太陽光ののせ方：リースか購入と容量を選ぶ。購入は購入価格（税込）を見積りの金額に書き換える。オール電化なら「エコキュートを昼の太陽光で沸かす」を選べる
  4. 右側の3段の階段（今のまま／ENEOSでんきに切り替え／さらに太陽光）と、10年・20年の合計で見せる
  5. 各段の根拠にマウスを乗せる（iPadは押す）と、使っている単価・出典・確認日が出る

困ったとき

オール電化なのにENEOSのオール電化プランがないのか聞かれた中国エリアにはありません（2026年10月時点）。時間帯で単価が変わらない中国Aプランで計算しています。太陽光でエコキュートを昼に沸かすと、夜の安さに頼らなくてよくなります。
切り替えると高くなると出た夜に使う割合が大きい家では、電化Styleコースのままの方が安いことがあります。正直にそのまま見せてください。
いつから発電するか聞かれた中国電力エリアは国の認定が下りてから電力網につなぐため、数か月かかることがあります。

提案パターン・ラボ

お客様のエネルギー方針と、重視している価値観を選ぶと、見せ方・言い回し・想定される反応と切り返しが出ます。社内の打ち合わせ準備用で、保存や試算はしません。

押す順番

  1. ① お客様のエネルギー方針を選ぶ
  2. ② 重視している価値観を選ぶ
  3. 下に出る流れ・キーメッセージ・トークスクリプトを確認する
  4. 選び直すときは 選択をリセット

取引先管理（管理者のみ）

工務店の登録と、対応する契約方式・PPAサービス・単価の設定をします。

押す順番

  1. 新しく登録するときは、工務店名などを入れて この内容で登録
  2. 直すときは一覧の行の 編集 を押し、リース料（円/kW・月額・税抜）や購入kW単価（税抜）を直して 保存する

困ったとき

画面が開けない管理者の権限がない場合は開けません。

どの画面でも共通

見た目の切り替え画面の隅の 暗め クリーン で切り替えます。数字は変わりません。
金額の書き方マイナスは「−」で表します。リース料と kW単価は税抜、購入の初期費用は税込です。
終わるときホームの「ログアウト」、または比較ナビ右上の「ログアウト」。
